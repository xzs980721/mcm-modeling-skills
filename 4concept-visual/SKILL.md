# 美赛背景图、解题路线与机制图

读取建模报告、结果报告、`plan.md` 中已确认的「论文图表风格」及图表清单、现有图表。按 [图表工作流](../_references/figure-workflow.md) 读取 `nature-figure` 入口。将计划中的配色、字体、字号、标注和图宽带入源图或提示词。图中文字使用英文。

## 三类必需图

| 图件 | 最少数量 | 作用与形式 |
| --- | --- | --- |
| 题目背景图 | 1 | 解释研究对象、场景、研究范围或关键约束，让读者迅速理解题意。至少一张背景定稿须用内置 Image2 文生图路线生成。 |
| 总体解题路线图 | 1 | 用可编辑矢量图交代题目输入、各问的联系、关键方法和结果验证。箭头依据实际依赖关系。 |
| 机制阐释图或系统工作图 | 1 | 优先阐释创新机制，显示它如何起作用。也可展示系统组件、资源流或反馈。按表达需要选可编辑矢量图或 Image2。 |

完整美赛流程或单独执行完整概念图阶段时，三类图分别交付。在此基础上，根据论文论证、建模与算法创新及复杂度决定是否为关键子问题、算法流程或其他机制增图。局部制作、修改或导出按请求范围执行。

## 按图件选择路线

- **矢量图。** 读取 `nature-figure` 的 `references/vector-schematic-workflow.md` 和 `references/vector-schematic-style-rules.md`。汇总正文位置、主要关系、图中术语和风格，请用户集中确认绘图简述后再绘制。保留可编辑 SVG，运行 `scripts/audit_svg_schematic.py`，导出论文用矢量 PDF，按实际版面宽度检查标签、箭头、对齐和留白。
- **生成图。** 使用下方的 [内置 Image2 路线](#使用内置-image2-生成图)。按 `nature-figure` 的提示词框架组织图稿，并通过 Codex 内置 Image2 出图。
- **已有背景素材。** 适合作为补充图件。核对其与题面相关性，记录来源、署名和使用条件。以裁切、标注和版面调整融入计划风格，同时保留素材依据。

已经选定 Image2 的图若遇到模型或工具不可用、当届规则限制或纳入条件未确认，将该图标为待用户决定。可保留内部草稿，等待用户决定是否调整图件或形式。继续制作其余图和撰写正文。必需图未齐时保留未完成状态。

## 使用内置 Image2 生成图

1. 读取 `nature-figure` 的 `references/ai-graphical-abstract-workflow.md`，根据题面、模型和 `plan.md` 写英文图稿简述。包括构图顺序、对象与关系、准确标签、画幅、背景和避用元素。核查当届 COMAP 规则及适用披露要求，确认可纳入论文后再确定论文用定稿。
2. 用 `nature-figure` 的 `scripts/generate_openrouter_schematic.py` 在离线模式生成完整提示词。将实际风格传给 `--style`，将图稿简述传给 `--prompt-file`，按需补充 `--title` 和 `--panel-map`，以 `--dry-run` 输出 JSON。保持脚本的标准模板，`--raw` 会跳过模板。
3. 从 JSON 提取 `prompt` 字段，原样交给 Codex 内置生图工具（Image2，`gpt-image-2`）。承担最低要求的背景图以该文本为唯一生成输入，参考风格可转写为配色、光线和构图等文字参数。其他生成图可随提示词传入获准使用的参考图。画幅等要求在图稿简述中写清，实际规格以出图为准。
4. 依据题面与模型逐项核对对象、关系、方向和文字。保存实际提交给 Image2 的完整提示词、模型与调用渠道、出图文件及审核记录。需调整时更新图稿简述并重新生成完整提示词，再出图复查。

## 定稿与交接

先核对内容和依据，再独立做一轮视觉迭代。按论文尺寸检查阅读顺序、色彩语义、留白、箭头和标签，修改后重新导出。定稿放入 `figures/`，图源和代表性的迭代记录随赛题保留。

在 `reports/CONCEPT_FIGURES_REPORT.md` 记录每张图的类别、用途、正文位置、建议英文图题、图源和定稿路径、来源或生成方式、视觉修改、实际尺寸检查结果及待定状态。标明承担最低要求的 Image2 文生图背景及完整提示词的保存位置。验收退回增图时同步更新该报告及 `plan.md` 的图表清单。

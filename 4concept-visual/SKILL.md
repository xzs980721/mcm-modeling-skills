# 美赛背景图、解题路线与机制图

读取题面、建模报告、结果报告、`plan.md` 中的图表清单和已确认风格。总体解题路线图遵循锁定母版，其余图件使用计划中的配色、字体、字号、标注和图宽。图中文字使用英文。

## 三类必需图


| 图件                   | 最少数量 | 作用与形式                                                                                                   |
| ---------------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| 题目背景图             | 1        | 解释研究对象、场景、研究范围或关键约束，让读者迅速理解题意。至少一张背景定稿须用内置 Image2 文生图路线生成。 |
| 总体解题路线图         | 1        | 由 [mcm-solution-roadmap](../mcm-solution-roadmap/SKILL.md) 用内置 Image2 生成。每个小问一个独立流程板块，呈现跨问联系和至少一处可辨识图示。 |
| 机制阐释图或系统工作图 | 1        | 优先阐释创新机制，显示它如何起作用。也可展示系统组件、资源流或反馈。按表达需要选可编辑矢量图或 Image2。      |

完整美赛流程或单独执行完整概念图阶段时，三类图分别交付。在此基础上，根据论文论证、建模与算法创新及复杂度决定是否为关键子问题、算法流程或其他机制增图。局部制作、修改或导出按请求范围执行。

## 图件交接与选型

- **总体解题路线图。** 将题面、建模与结果报告交给 [mcm-solution-roadmap](../mcm-solution-roadmap/SKILL.md)。共享区呈现实际共用的模型或接口，各问板块展示采用的主方法、必要扩展、关键输出及验证，底部汇总赛题要求的答案。仅画有依据的共享输入和跨问传递。将装配好的完整英文提示词原样交给 Codex 内置 Image2。重试美化或补回图中漏项时复用完整提示词，优先调整图上空间、分组或单个标签。事实或术语需更正时按 [局部修订规则](../mcm-solution-roadmap/references/image2-prompt.md#局部修订与覆盖检查) 只改有关项目。用两张表核对成图，保留内容 JSON、完整提示词、原始成图、模型及检查记录。
- **机制阐释图或系统工作图。** 按需要讲清的机制、组件和关系检索，优先选机制图与系统工作图卡，再用含相关局部结构的总体路线图卡补足 5 张。核对原图和正文，重点借鉴箭头、层次、局部放大或对照布局等具体画法。用当前方案的真实对象、输入输出、状态、反馈或资源流重新组织，按所需的关系精度和表现形式选择向量图或 Image2。

在 `reports/CONCEPT_FIGURES_REPORT.md` 记录路线图的逐问与跨问核对、母版一致性、提示词及成图位置。将路线图的论文位置记为 `Introduction` 的总体思路小节，同步到 `plan.md` 图表清单。对机制图或系统工作图记录候选、原图定位、采用的画法和风格适配。

## 按图件选择路线

- **矢量机制图或系统工作图。** 按共享的 [向量示意图路线](../_references/figure-workflow.md#绘制向量示意图) 制作与验收。
- **背景图、机制图或系统工作图的生图路线。** 按共享的 [内置 Image2 路线](../_references/figure-workflow.md#使用内置-image2-生成图) 出图。承担最低要求的背景图以纯文本为唯一输入，将参考风格转写为配色、光线和构图等参数。
- **已有背景素材。** 适合作为补充图件。核对其与题面相关性，记录来源、署名和使用条件。以裁切、标注和版面调整融入计划风格，同时保留素材依据。

已选定由 Image2 生成定稿的图若遇到模型或工具不可用、当届规则限制或纳入条件未确认，将该图标为待用户决定。可保留内部草稿，等待用户决定是否调整图件或形式。继续制作其余图和撰写正文。必需图未齐时保留未完成状态。

## 定稿与交接

先核对内容和依据，再独立做一轮视觉迭代。按论文尺寸检查阅读顺序、色彩语义、留白、箭头和标签，修改后重新导出。定稿放入 `figures/`，图源和代表性的迭代记录随赛题保留。

在 `reports/CONCEPT_FIGURES_REPORT.md` 记录每张图的类别、用途、正文位置、建议英文图题、图源和定稿路径、来源或生成方式、视觉修改、实际尺寸检查结果及待定状态。标明承担最低要求的 Image2 文生图背景及完整提示词的保存位置。验收退回增图时同步更新该报告及 `plan.md` 的图表清单。

# 美赛背景图、解题路线与机制图

读取题面、建模报告、结果报告、`plan.md` 中的图表清单和已确认风格。各图使用计划中的全局配色。总体解题路线图按锁定母版装配，将全局 HEX 色值和对应语义写入提示词的配色段。其余图件的字体、字号、标注和图宽遵循计划。图中文字使用英文。

## 三类必需图


| 图件                   | 最少数量 | 作用与形式                                                                                                   |
| ---------------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| 题目背景图             | 1        | 解释研究对象、场景、研究范围或关键约束，让读者迅速理解题意。至少一张背景定稿须用内置 Image2 文生图路线生成。 |
| 总体解题路线图         | 1        | 由 [mcm-solution-roadmap](../mcm-solution-roadmap/SKILL.md) 用内置 Image2 生成。每个小问一个独立流程板块，呈现跨问联系和至少一处可辨识图示。 |
| 机制阐释图或系统工作图 | 1        | 用内置 Image2 生成，优先阐释创新机制如何起作用，也可展示系统组件、资源流或反馈。 |

完整美赛流程按 `plan.md` 的分配交付至少 4 张概念图，涵盖三类独立必需图和至少一张承担不同论证任务的概念图。单独执行完整概念图阶段也至少交付 4 张。可围绕关键子问题、算法流程或扩展机制增图。计数按[正文图件数量与计数](../_references/figure-workflow.md#正文图件数量与计数)，局部制作、修改或导出按请求范围执行。

## 图件交接与选型

- **总体解题路线图。** 将题面、建模与结果报告交给 [mcm-solution-roadmap](../mcm-solution-roadmap/SKILL.md)。共享区呈现实际共用的模型或接口，各问板块展示采用的主方法、必要扩展、关键输出及验证，底部汇总赛题要求的答案。仅画有依据的共享输入和跨问传递。将装配好的完整英文提示词原样交给 Codex 内置 Image2。每轮修订按 [局部修订与覆盖检查](../mcm-solution-roadmap/references/image2-prompt.md#局部修订与覆盖检查) 执行，发送前核验完整提示词，禁止发送概括版 revision。出图后按两张表在印刷尺寸逐项定位公式、参数、约束、操作、结果、检验与连线。漏项、合并、降级成概括标签或无法独立阅读时，该版退回调整并重验。保留内容 JSON、实际发送的完整提示词、局部修改、原始成图、模型及逐项核对记录。
- **机制阐释图或系统工作图。** 按需要讲清的机制、组件和关系检索，优先选机制图与系统工作图卡，再用含相关局部结构的总体路线图卡补足 5 张。核对原图和正文，重点借鉴箭头、层次、局部放大或对照布局等具体画法。以本题真实对象、输入输出、状态、反馈或资源流组织视觉表达，并用内置 Image2 完成最终稿。

完整流程中，从 `RESULTS_REPORT.md` 定位最终入选基础模型及其已核验的图件方案。基于同一组科学内容比较两种实质不同的视觉构思，例如逐级分流与累积层叠。两案须在机制的视觉编码或空间叙事上有差异，单纯换色或移位置不足以构成第二案。比较各案新增的可见关系、焦点、阅读节奏、比例、留白及论文尺寸下的可读性。保留图件的论证目标、关键对象与已验证关系，选定最有想象力、创造力和美学感染力且能准确表达机制的一案，用 Image2 绘制并按实际图宽迭代。在 `CONCEPT_FIGURES_REPORT.md` 记录入选模型编号、两种构思、选择理由、版式调整及科学关系核对结果。成稿讲清论文核心机制时可计入必需机制图或系统工作图。后续扩展有独立论证价值时可再增图。单独执行本阶段或沿用旧成果缺少该方案时，根据已采用模型及可核验依据补写图件说明。

在 `reports/CONCEPT_FIGURES_REPORT.md` 记录路线图的逐问与跨问核对、母版一致性、提示词及成图位置。将路线图的论文位置记为 `Introduction` 的总体思路小节，同步到 `plan.md` 图表清单。对机制图或系统工作图记录候选、原图定位、采用的画法和风格适配。

## 按图件选择路线

- **背景图、机制图或系统工作图的生图路线。** 按共享的 [内置 Image2 路线](../_references/figure-workflow.md#使用内置-image2-生成图) 出图。承担最低要求的背景图以纯文本为唯一输入，将参考风格转写为配色、光线和构图等参数。机制阐释图及承担相同用途的系统工作图使用 Image2 成稿，禁止转向量或用向量绘制替代。
- **补充的算法或任务流程图。** 可按 [向量示意图路线](../_references/figure-workflow.md#绘制向量示意图) 表达步骤和分支。兼有步骤和机制的图按主要论证用途判定，主要用于阐释机制时使用 Image2。总体解题路线图按其锁定母版另行生成。
- **已有背景素材。** 适合作为补充图件。核对其与题面相关性，记录来源、署名和使用条件。以裁切、标注和版面调整融入计划风格，同时保留素材依据。

Image2 图件若遇到模型或工具不可用、当届规则限制或纳入条件未确认，将该图标为待用户决定。可保留内部草稿，继续制作其余图和撰写正文。必需图未齐时保留未完成状态。

## 定稿与交接

先核对内容和依据，再独立做一轮视觉迭代。按论文尺寸检查阅读顺序、色彩语义、留白、箭头和标签，修改后重新导出。定稿放入 `figures/`，图源和代表性的迭代记录随赛题保留。

在 `reports/CONCEPT_FIGURES_REPORT.md` 记录每张图的类别、用途、正文位置、建议英文图题、图源和定稿路径、来源或生成方式、视觉修改、实际尺寸检查结果及待定状态。标明承担最低要求的 Image2 文生图背景及完整提示词的保存位置。验收退回增图时同步更新该报告及 `plan.md` 的图表清单。

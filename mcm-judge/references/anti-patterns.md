# 别学清单与扣分点

分两类：**扣分点**（评委明确不买账的做法，来源是 COMAP 官方指引与语料统计）与**别学清单**（语料里出现过、但不该模仿的做法）。后者尤其重要——把某篇 O 奖论文的个性当标准，是做美赛最隐蔽的错。

---

## 扣分点

| 做法 | 为什么扣 | 替代做法 |
|---|---|---|
| 摘要复述题目 | COMAP 原文点名："Summaries that are mere restatements of the contest problem… are generally considered to be weak" | 摘要写你做了什么、得到什么数 |
| 摘要没有具体数字 | 近五年 97% 的 O 奖摘要含数字结论 | 每问至少一个量化结果 |
| 假设只列不证 | 官方要求 "state and **justify** reasonable assumptions" | 每条假设后加一句依据 |
| 检验只有"结果稳定" | 官方要求 error analysis / sensitivity / stability | 说明结论在什么参数范围内成立 |
| 局限性写成免责声明 | "由于时间限制未做…"不构成分析 | 写具体局限 + 影响哪条结论 + 怎么改进 |
| 结论不回扣子问题 | 官方要求 "Provide a conclusion and report results explicitly" | 逐问给数字答案 |
| 参数无来源 | 评委无法复现，也看不出你是否真算过 | 标定/文献/估计，三者写明其一 |
| 图表无单位、无自解释图注 | 官方要求 solution 让读者能跟上 | 图注写"这张图说明什么"，不是"某某结果" |
| 正文塞代码 | 官方明确 code 计入 25 页，且评委不看代码 | 代码进附录或省略，正文只留算法步骤 |
| 伪造或凑数引用 | 引用必须可查；查不到等于自曝 | 只引真读过的，7–10 条足够 |

## 别学清单

**N1｜别追求"每页都有图"。**
近五年图表/页中位 0.68–0.94，P25 低到 0.42。为满足"每页一张"而加图，产出的就是凑数图——评委对凑数图的容忍度远低于对空白的容忍度。

**N2｜别把 A 题的图数套到 F 题。**
A 题图中位 20，F 题 13。跨题搬数字会逼出无意义插图。

**N3｜别硬造 baseline。**
`baseline` 在 O 奖论文里出现率只有 14%。MCM 不要求你跑对照组，要求你解释"为什么用这个模型"。硬造一个弱对照组反而暴露你不理解问题。

**N4｜别用机器学习黑话包装检验。**
`ablation study` 出现率 2%，`sensitivity` 92%。写"我们做了消融实验"不加分，写清"参数变了结论还在不在"才加分。

**N5｜别为凑章节写空洞结论。**
带独立 Conclusion 章的只有 33–48%。有一章空话，不如把结论并入优劣势章写实。

**N6｜别模仿单篇的章节命名和篇章顺序。**
语料里章节标题差异极大（"Senitivity Analysis" 这种拼写错误都有）。结构要服务于你自己的论证主线，不是抄版式。

**N7｜别把"符号表"当必需。**
`notation` 章只有 33–57%。符号多才需要表。

**N8｜别用附录灌页数。**
2021 年起 25 页是上限且含附录，灌不出分，只会挤压正文。

**N9｜别写"模型具有较高的准确性/较强的实用性"。**
这类句子无法验收，评委读到的信息量为零。换成数字或具体对象。

**N10｜别在摘要里堆方法名。**
摘要要的是"做了什么 → 得到什么 → 边界在哪"，不是技术栈清单。

## 用法

- **brief 模式**：把本表压缩成 5–6 条最相关的写进 `AWARD_BRIEF.md` 第 4 节，不要整表照搬（3 小时内读不完等于没写）。
- **review 模式**：发现命中某条时，扣分扣在对应维度，并在改法表里引用条目编号（例如"命中 N3：硬造 baseline"），方便追溯。

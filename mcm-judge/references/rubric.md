# 六维评分卡（事前事后双读）

每一条都有两个用法：**动笔前当动作清单**（我要产出什么），**成稿后当判据**（这段做到了没有）。两用同一条，是为了避免"写的时候看的"和"评的时候算的"变成两套标准。

判据里的数字全部来自 `references/problems/<题号>.md`，本文件只写锚点。引用时把具体数字填进去。

---

## 1. 建模过程（权重 30）

这是美赛最看重、也最难假装的一维。评委要看到的不是"用了什么模型"，而是"**为什么是这个模型**，以及这个理由是不是从题目长出来的"。

| 分 | 判据（成稿后） | 对应动作（动笔前） |
|---|---|---|
| 0–2 | 直接给方法名，没有选择理由；参数凭空出现 | — |
| 3–4 | 有推导，但"为什么用这个"或"参数从哪来"缺一项 | 写下模型选择的理由句 |
| 5–6 | 有归因式论证（问题特性 → 模型特性），参数来源交代清楚 | 给每个参数标来源：标定／文献／估计／设值 |
| 7–8 | 论证闭合：问题特性 → 模型特性 → 参数 → 结果，且有一处对照或检验 | 补一条"考虑过但没选"的替代方案及理由 |
| 9–10 | 闭合 + 有取舍记录 + 结果回到决策（给谁、怎么用） | 写"结果翻译成建议"那一段 |

**什么是归因式论证**：从题目的结构特点出发推出方法要求，而不是"因为文献里常用"。语料里最常见的形态是"考虑空间异质性 → 用地理加权回归"、"变量维数 96 → 先降维"。这类句子可以整句引用进评语。

**扣分点**：模型名堆叠而无比较；用"先进""流行"当理由；参数写"经调试确定"却没有过程。

## 2. 模型（权重 20）

| 分 | 判据 |
|---|---|
| 0–2 | 与问题结构不匹配，或形式化到无法求解 |
| 3–4 | 能跑，但变量含义不清、约束不全、边界没交代 |
| 5–6 | 正确完整，但停留在教科书形态（套用现成框架） |
| 7–8 | 完整 + 至少一处针对本题的改造或扩展，且说明改了什么 |
| 9–10 | 改造是必要的，并能解释"原模型为什么不够" |

评这一维只看两件事：数学上站不站得住，以及有没有为这道题动过手。**高级不等于好**——一个能解释清楚的简单模型，通常高于一个解释不清的复杂模型。

## 3. 检验与稳健性（权重 15）

| 分 | 判据 |
|---|---|
| 0 | 没有 |
| 1–3 | 只有定性表态（"结果合理""符合直觉"） |
| 4–6 | 有定量检验，但只测了一个点或一个方向 |
| 7–9 | 参数扫描／交叉验证／消融，且明确说出"结论在什么条件下仍成立" |
| 10 | 多手段交叉 + 明确界定适用范围 |

判据落在**"有没有界定适用范围"**，不落在篇幅。语料里存在只用一段话 + 一张图就拿 O 奖的检验节，也存在写了三页全是图的。所以：不要按长度给分，按"是否让读者知道结论的边界"给分。

术语陷阱：这一节常被写成 `robustness check`、`ablation study`、`stability analysis`，标题里没有 `sensitivity` 三个字也算数。判定看论证，不看关键词。

## 4. 内容与结构（权重 15）

| 分 | 判据 |
|---|---|
| 0–3 | 有子问题没答，或答了但没给数字 |
| 4–6 | 每题都有答案，但结构性内容缺失（假设无理由、结论不回扣） |
| 7–8 | 假设有理由且在后文被用到；结论逐问回扣；篇幅分配合理 |
| 9–10 | 以上全部 + 章节顺序让读者能顺着一条主线读完 |

动笔前的动作：**先建"子问题 → 模型 → 结论"三列对照表**。这张表填不满，正文一定写到一半发现漏答。

---

## 5. 摘要（权重 12）

| 分 | 判据 |
|---|---|
| 0–3 | 复述题目；或没有具体结果 |
| 4–6 | 有方法与结论，但没有数字或没有取舍 |
| 7–8 | 独立成篇：背景一句、方法链、逐问结果带数字、一句检验、一句结论 |
| 9–10 | 以上 + 让读者能判断"这篇与别的解法差在哪" |

摘要不是"第一句必须甩结论"。语料里 O 奖摘要的常见开头是背景一句，第三四句才进方法。**按"读完能不能知道结论"判，不按"第一句是否惊人"判。**

---

## 6. 图表与排版（权重 8）

| 分 | 判据 |
|---|---|
| 0–3 | 有图表但脱离正文看不懂；或页数/格式违规 |
| 4–6 | 图表能读，但存在无单位、无图注、与正文重复叙述 |
| 7–8 | 每图承载一个正文结论；图注自解释；页数经济 |
| 9–10 | 以上 + 图表承担了论证（读者看图即可得结论） |

动笔前的动作：**先列图表清单（每张图要说什么），再写正文。** 图表决定叙事顺序，反过来写会写成流水账。

注意：图数没有统一标准，各题差异很大。按 `problems/<题号>.md` 的分位判，不要套别题的数。

## 档位换算

| 加权总分 | 档位 |
|---|---|
| ≥ 85 | 接近 O 奖 |
| 65–84 | M–F 之间 |
| < 65 | H 以下 |

阈值未校准（语料只有 O 奖，无法用对照组验证）。用变异测试检查过之后再定稿；在此之前，**档位只用于给用户一个大方向，不作为承诺**。

## 评分纪律

1. 每个扣分项必须能引出一句原文或指出一个位置。引不出来就不扣。
2. 不评"文笔好坏""AI 味"。只评能落到句子的性质。
3. 同一处问题只扣一次，扣在权重最高的那个维度上。
4. 改法必须写"改成什么"，不能只写"建议加强"。

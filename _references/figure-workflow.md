# 美赛论文图表工作流

## 先按论文论证规划

在 `plan.md` 记录每张图或表的拟用章节、要回答的问题、数据或依据、图型、文件名和状态。单独执行某一阶段时，将同样的信息记入该阶段的报告，并沿用可用的现有风格。

- 引言安排至少一张题目背景图，例如场景示意、研究范围图或关键对象图。
- 方法安排至少一张矢量总体解题路线图，并另设至少一张机制阐释图或系统工作图。优先展示创新机制及其作用。
- 结果逐问覆盖关键证据，按需要使用对照图、权衡曲线、空间分布、时间变化或精确数值表。
- 验证优先展示能改变选型或结论的基线比较、极端情景、消融和灵敏度。可以用同尺度多面板组织可比结果。

三类必需概念图之外，按论文论证需要、模型或算法的创新性与复杂度决定是否增图。避免把相同结果同时做成多张近义图表。

## 由用户选择整篇论文的图表风格

启动时提供适合本题的风格预设，也接受用户描述或参考图。将已指定的选择直接记入 `plan.md` 的「论文图表风格」。如果选择尚未明确，先请用户选定，再开始出图。单独调用绘图阶段也沿用该约定。

把选择落实为可跨阶段复用的参数，包括风格名或参考来源、适合版心的常用图宽、渲染后文字大小和字体、主题色和强调色，以及基线、候选和各情景的固定颜色、线型或标记。统一数值精度、单位、面板标签、线宽、图例和边距。同一对象在数据图、概念图与表格中保持名称和颜色语义一致。关键对照使用线型、形状或文字辅助辨认。

## 按图件类型使用 nature-figure

优先读取当前环境已启用的 `nature-figure` 的 `SKILL.md`。同一工作区若提供了本地副本，也可沿用。资源和脚本路径从实际的 skill 目录解析。依赖缺失时记录具体缺项，并继续独立的分析、计算或写作。

- 第 3 阶段使用数据绘图路线，从计算结果生成论文用矢量 PDF。按 `nature-figure` 选择 Python 或 R，运行对应的源文件、导出 PDF、碰撞和多面板对齐检查。
- 第 4 阶段使用向量示意图或 Image2 路线。将用户选择的风格参数带入确认过的向量图简述，或写入 Image2 的提示词与成稿复核。流程图与概念图不经数据绘图后端选择。

## 先核实内容，再迭代视觉

1. 渲染初稿。核对每条数据序列、单位与刻度，核对图示的对象、箭头和关系是否有题面或报告依据。
2. 按统一风格美化。检查对齐、层级、留白、图例和标注位置。相关面板采用可直接比较的尺度和顺序，轴范围、聚合或变换有明确理由时在图题或正文中说明。
3. 在计划使用的论文宽度查看，检查缩小后文字、线条、色差和局部拥挤。修图后重新导出。在阶段报告中保存代表性的初稿与定稿位置及具体改动。初稿和诊断图可放在 `figures/drafts/`。
4. 论文编译后再次逐页查看。优先修源图，再重新嵌入并编译。核查图题、正文引用、图表可读性和跨章节的一致性。

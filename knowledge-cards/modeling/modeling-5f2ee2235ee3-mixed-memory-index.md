# 按指标时间效应切换最新值与衰减历史权重

## 原题与基线

冲击型指标与缓变指标用同一时间平均会混合不同信息。

## 建模机制与求解

瞬时效应取最新值，持续项用归一化指数衰减权重，再将安全、政策、经济与长期气候项合成。

## 验证与局限

对时间衰减参数和极端天气概率做敏感性分析，缺失和选择指标会影响国家比较。

## 迁移到新题

提供每项记忆窗依据，留出年份测试并分层报告各类输入缺失对排序的影响。

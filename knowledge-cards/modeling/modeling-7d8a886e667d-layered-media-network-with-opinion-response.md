# 区分地区内与地区间连通并以历史媒体校验

## 原题与基线

不同地区与媒介技术有异质的联系容量。

## 建模机制与求解

地区内个体图按媒介与接收指标设置联系概率，地区之间另建连接层，并把典型媒体时间份额和有界信心动态纳入情景。

## 验证与局限

对报纸及互联网份额报告相对误差并比较美国和刚果，资料异质限制因果解释。

## 迁移到新题

保持地区图和个体图两个粒度，以其他时段验证份额与预测时滞。

## 证据定位

- PDF 第 4–13 页，构网和指标。
- PDF 第 14–18 页，历史及情景。
- PDF 第 18–20 页，观点变化。

# 把节点层的信息受众与状态转移图配对

## 入选理由

表达创新或视觉张力。从局部社交网到群体状态区分对象和过程。

## 论证任务

解释图中节点哪些是个人、哪些是抽象状态。

## 图型与输入

局部节点图有中心和方向边；状态图采用蓝框或椭圆、带符号有向转移。

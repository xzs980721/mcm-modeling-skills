# 单篇论文知识卡

**边界：本技能评的是"卡片好不好用"，不是"这篇论文好不好"。** 五维分数衡量证据可追溯性与可迁移性，与论文的获奖等级无关；论文等级来自 `../mcm-judge/data/features.json` 里的语料索引（按 PDF 的 SHA-256 关联）。不要用卡片分数推断论文水平。

输入是一篇论文 PDF 和用户指定的输出根目录。沿用当前请求或会话里已明确的知识库路径。缺少 PDF 或输出位置时，只询问缺少的输入。按 [卡片格式](references/card-format.md) 将卡片写成 UTF-8 Markdown，分别保存到输出根目录的 `modeling/` 和 `visualization/`。

## 提取流程

1. **确认来源。** 读取论文首页和目录，核实标题、题目、年份及文件完整性。建立 PDF 物理页码（首页为第 1 页）与论文页脚页码的对应关系。先逐页提取文本并定位方法、求解、检验、图表与附录。扫描件可对相关页面做 OCR。公式、数字或图示有疑义时渲染原页核对。
2. **筛选方法。** 追踪「问题结构 → 假设或基线 → 新增机制 → 求解 → 检验」的证据链。优先提炼改变决策或解释的做法。一张卡只讲一个可迁移的做法。若论文未给基线、参数或检验，记录缺口及其影响。
3. **盘点并拆解图表。** 按 [图表覆盖规则](references/visual-coverage.md) 逐页查看整篇 PDF。对每张有表达创新或视觉张力的图表提炼卡片，覆盖图表整体与具备独立表达价值的面板。核对图题、正文讨论、图例、坐标、单位、箭头和面板顺序，将图表做法转写为可用新数据或题意重绘的方案。缺失的源数据或读不清的数值记为缺项。
4. **写卡和评分。** 将范文已说明的事实、证据缺口和面向新题的迁移建议分开。核心做法须能回查 PDF。用 [评分细则](references/scoring.md) 逐维给整数分，逐项写可复核的理由，汇总到卡片元数据。作者获奖、算法名字新颖、图面复杂度均不单独计分。
5. **复核后落盘。** 对照原页核实关键证据、坐标单位、公式或图号。检查卡片类型、来源定位、五项得分、总分及分档是否一致。查阅同一 PDF 的已有卡，核实每项合格图表的具体做法是否已覆盖。补提遗漏，保留同源且解决不同问题的卡。写入后核对图表清单、卡片路径和可回查的来源位置。

两类都筛查。图表卡以覆盖所有命中项为完成条件，不设张数上限。交付时列出新增卡及分数，并报告图表盘点中的新增、已有覆盖、排除和待核数量。某类没有可核实的候选时，注明缺口。

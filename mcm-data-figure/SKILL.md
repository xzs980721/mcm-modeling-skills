# 美赛数据图生成

输入为已确认的数据或求解结果、要表达的结论及图表风格。已有 `plan.md` 时沿用其中的图表清单和风格。单独调用时用用户指定的输入、风格和输出位置，按 [风格约定](../_references/figure-workflow.md#由用户选择整篇论文的图表风格) 补齐缺项。按请求范围出图，无需重跑求解或完成其他赛题阶段。

## 选型与绘制

1. 写清读者要判断的关系、数据结构和变量的物理意义。按 [图表卡检索与原文核对规则](../_references/figure-workflow.md#检索并核对图表知识卡) 为每个表达任务返回 5 张候选，优先选择适配数据和论证的非常规图型或组合编码。核对原图的坐标、单位、变换和视觉编码。仅调色或重新导出时沿用原选型记录。
2. 若候选都是常规图或都不适用，从当前数据独立设计能揭示额外关系的表达，与简洁的常规图比较。桑基图用于守恒流量或类别转移，平行坐标用于多指标权衡，分布脊线图用于情景间分布对比。组合图可用折线、柱形等元素表达约束、转移、分布或权衡。普通柱状图、饼图和折线图在更清楚、准确时可用于单张图。改色、装饰和简单拼接按原图型处理。
3. 确定当前字段、单位和变换到图形的映射。按 [`nature-figure` 入口](../_references/figure-workflow.md#按图件类型使用-nature-figure) 选择 Python 或 R，直接编写绘图代码或复用合适的模板。可用 [内置 Image2](../_references/figure-workflow.md#使用内置-image2-生成图) 探索布局或生成非定量素材。坐标、刻度、曲线、点位、面积、流带宽度和精确标签由代码根据当前数据生成。
4. 先核对初稿的数据和比例，再按论文风格独立美化。在拟用版面宽度执行 `nature-figure` 的适用渲染检查。定稿为 PDF，保留可检查的定量矢量层。嵌入的插画需清晰可辨，与定量图形界限明确。图中使用英文坐标、单位、图例和说明，标题交给论文图题，图内避免大标题。

## 交付

- 完整美赛流程或完整的第三阶段至少交付一张表达关键发现或关系的非常规数据图。在 `plan.md` 标明拟用章节、对应图件及核心发现。仅制作指定图件时沿用用户范围。
- 交付定稿 PDF、绘图源代码、数据定位和简短选型记录。记录候选及原图定位、独立设计、字段映射、代表性改动和校验结果，使用 Image2 时附生成记录。完整阶段将定稿放入 `figures/`，记录写入 `reports/RESULTS_REPORT.md`。独立任务按指定位置交付，未指定时沿用当前项目的图表及报告目录。

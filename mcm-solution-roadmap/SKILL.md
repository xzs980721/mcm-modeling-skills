# 美赛总体解题路线图

优先读取用户提供的原题和建模报告，再用论文、结果报告与可复现输出校对实际求解流程及数值。依据不全时，在相应内容中用英文标记缺项。使用 [锁定母版](references/image2-template.txt) 和 [填写指南](references/image2-prompt.md)。

## 总体解题路线图设计

1. **填三项内容。** 从逐问内容表与跨问连线表提炼 `WHAT`、`HOW_TO_MODEL` 和 `HOW_TO_SOLVE`。保留题面全部明确小问和原有编号，未编号问询沿用建模报告中可追溯的工作编号。每个小问恰有一个板块，展示采用的主方法和必要扩展。共享模型或接口、直接依赖及最后的综合输出以实际工作为准。
2. **使用全局配色。** 从 `plan.md` 的「论文图表风格」读取已确认的 HEX 色值和语义，填入 `PALETTE`。单独执行时也可使用用户已确认的色板。缺少已确认色板时先确定配色，再生成提示词。母版固定共享区、逐问网格、跨问数据流、底部综合区、板块五步结构，以及画幅、字体、图示和质量要求。
3. **按样例的细粒度装配。** 在三项英文内容中分行列出各输入、公式、约束、实际计算步骤、结果和检验。每项保留用途、条件和必要数值。用 `scripts/render_image2_prompt.py` 填入母版，核对小问、各项内容、连线语义、全局色值及固定文本。缺项标为 `Not documented`，只在有依据时补充。保留含配色的内容 JSON 与完整提示词。
4. **强制等量、等细粒度修订。** 以通过核对的完整母版提示词、内容 JSON 和两张核对表为基准。每轮都发送脚本装配的完整提示词。只需调整构图时用 `--revision-actions` 追加局部动作，事实更正用 `--patch` 精确修改指定片段。发送前执行 `--check-prompt`，成图后逐项检查内容和连线。禁止用摘要、单独的 revision 文字、旧图或“每阶段只留一个标签”替代完整版。发现漏项、合并、变粗或不可辨时退回修正。按 [局部修订与覆盖检查](references/image2-prompt.md#局部修订与覆盖检查) 执行。

## 交付

独立调用只输出脚本生成的一份完整英文 Image Generation Prompt，可直接复制使用。完整论文流程中，将这份提示词及核对依据交给 `4concept-visual`，由该阶段原样调用 Codex 内置 Image2 并逐问验收成图。

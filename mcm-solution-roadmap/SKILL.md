# 美赛总体解题路线图

优先读取用户提供的原题和建模报告，再用论文、结果报告与可复现输出校对实际求解流程及数值。依据不全时，在相应内容中用英文标记缺项。使用 [锁定母版](references/image2-template.txt) 和 [填写指南](references/image2-prompt.md)。

## 总体解题路线图设计

1. **填三项内容。** 从逐问内容表与跨问连线表提炼 `WHAT`、`HOW_TO_MODEL` 和 `HOW_TO_SOLVE`。保留题面全部明确小问和原编号，每个小问恰有一个板块。公共输入、直接依赖及最后的综合输出以实际工作为准。
2. **锁定设计语言。** 母版固定共享区、逐问网格、跨问数据流、底部综合区和板块五步结构，以及画幅、配色、字体、图示和质量要求。`plan.md` 中的其他图表风格适用于对应图件。路线图始终使用母版的视觉规范。
3. **按样例的细粒度装配。** 在三项英文内容中分行列出各输入、公式、约束、实际计算步骤、结果和检验。每项保留用途、条件和必要数值。用 `scripts/render_image2_prompt.py` 填入母版，核对小问、各项内容、连线语义及固定文本。缺项标为 `Not documented`，只在有依据时补充。保留三项内容 JSON 与完整提示词。
4. **从上一版做局部修改。** 先载入上一版内容 JSON 和两张核对表。纯视觉重试直接复用完整提示词。事实或术语变更用脚本的 `--patch` 按行修订，只改用户要求或原文核实的项目。逐项对照修改前后，确认其余公式、约束、步骤、结果和检验全部保留，独立步骤仍可分别定位。需要修订时按[填写指南](references/image2-prompt.md#局部修订与覆盖检查)执行。

## 交付

独立调用只输出脚本生成的一份完整英文 Image Generation Prompt，可直接复制使用。完整论文流程中，将这份提示词及核对依据交给 `4concept-visual`，由该阶段原样调用 Codex 内置 Image2 并逐问验收成图。
